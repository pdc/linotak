# Thumbnail editor for Linotak

This is a simple JavaScript-powered UI for selecting the focus point for an
image in Linotak (as such it is only used by editors).

## Stack

- The contents of `src/fw`
- Signals polyfill

The Signals API is an emergent JavaScript API for the style of app where
updating a state variable indirectly causes changes to the DOM to represent that
change. Normally Signals would be used to implement a full-featured framework
like [Svelte] or Vue, but for now we are using Signals directly. The reason for
this is to keep the JavaScript to a minimum & reduce the number of hacks needed
to use this on a Django page (instead of being the whole app as most frameworks
are designed to be).

## Tests

No unit tests as yet (!)

## Running dev server

This is a [Vite] project. Run the dev server with this command:

```sh
npm run dev
```

This uses `index.html`, which is set up like the page that is generated by the
Django site—the image element & form are in place, and the JavaScript will
automatically replace the image with the UI.

The image used on the test page is only used by the dev server; neither it nor
the `index.html` are copied in to the Django app.

## Updating the Django app

At the top level of the project, run `make`. This will run the Vite `build` command
and copy the resulting bundled JavaScript file in to the Django app.
